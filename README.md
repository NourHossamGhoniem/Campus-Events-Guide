Campus Events Guide

About the Project

Campus Events Guide is a website designed to help students discover what's happening around campus. It brings event information together in one place, making it easier to explore activities, check dates and venues, view schedules, and find registration details.

This project was created for Assignment 1 of SW302 – User Interface Development. The main goal is to practice building a complete, responsive website using HTML and CSS.

Pages

Home (index.html): Introduces the website and highlights featured campus events.

Events (events.html): Displays upcoming and past events with their posters, dates, venues, and categories.

Event Details (event-details.html): Provides detailed information about a featured event, including its description, agenda, media, and review form.

Schedule (schedule.html): Shows the campus events timetable in a structured table.

Registration (registration.html): Includes event information and a registration form with HTML5 validation.

Technologies Used

HTML5 for the page structure and content.

CSS3 for styling, layouts, and responsive design.

Features

Consistent navigation across all five pages.

Event cards with relevant images and information.

A timetable with clear column headings.

Registration and review forms with appropriate labels and browser validation.

Responsive layouts using Flexbox, CSS Grid, and media queries.

CSS variables for consistent colors and styling.

A CSS-only dark mode toggle.

Shared styling and a consistent design across the website.

How to Run the Project

Clone or download this repository.

Open the project folder in Visual Studio Code.

Open index.html in a browser such as Google Chrome or Microsoft Edge.

Navigate through the pages to explore the website.

No additional libraries or frameworks are required.
